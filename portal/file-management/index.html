File management and WebDAV

The portal’s file browser is the simplest way to maintain individual files. It supports the operations appropriate to each exposed storage area: upload and download, folder creation, rename, deletion, and in-browser editing of supported text configuration.

Before overwriting or deleting important material, download a backup. Deletion cannot be undone. Structured configuration is checked when saved, but semantic mistakes such as a valid yet incorrect server address are still possible.

Advanced desktop clients can mount the exposed storage through WebDAV. OmniRadio implements the practical file operations needed by common clients, not a general-purpose server. Only supported paths are visible, protected system content remains restricted, and a client must not assume every optional WebDAV feature is available.

Network file access pauses while the same user storage is exported as an external USB drive. Disconnect or exit USB-drive mode before reconnecting a WebDAV client.
