Hardware settings

Hardware assignments are stored in Configuration / system / pconfig.json. They are integer GPIO numbers; -1 disables an absent function. All recognized fields must be present and valid.

Group Fields Purpose Restart
I2C sda, scl Shared control bus Required
SI4732 si_interrupt, si_reset Receiver control Required
SI4713 si4713_reset, si4713_interrupt FM transmitter control Required
Shared I2S i2s_bclk, i2s_lrclk, i2s_dummy_out Audio clocks Required
I2S data i2s_dout, i2s_dout_fm, i2s_adc_din, mic_din Speaker, transmitter, ADC, and microphone data Required
Audio control adc_reset, amp_left_sd, amp_right_sd ADC reset and amplifier enables Required
SPI spi_sck, spi_mosi, spi_miso Shared display/storage bus Required
Display tft_dc, tft_reset, tft_cs, tft_backlight ST7789 control Required
Storage sd_cs SD-card chip select Required
Input button_mode, button_minus, button_plus Physical controls Required
Power battery_adc Divided battery-voltage input Required

The portal offers a restart after saving because the map is read during boot. It checks file structure and GPIO-number range, but cannot prove that the wiring is electrically safe. Follow Initial hardware configuration and Shared buses and pins.
