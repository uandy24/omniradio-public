Install OmniRadio over USB

Caution

The first-install procedure erases the entire flash. Do not use it for a normal update, and back up any device that already contains data.

Connection options

Section titled “Connection options”

The ESP32-S3 ROM download mode accepts this image through either of these connections:

  • Native USB: connect the ESP32-S3 USB D− and D+ interface exposed by the board. This is the simplest option on a board with a working native USB connector.
  • External USB-to-UART adapter: connect a 3.3 V logic-level adapter to ESP32-S3 UART0, cross adapter TX to module RX and adapter RX to module TX, and connect ground. The board must also provide access to GPIO0/BOOT and EN/RESET when automatic download-mode control is absent.
  • Board-mounted USB-to-UART bridge: boards using CP210x, CH340x, FTDI, or a similar bridge work like the external adapter. A board with DTR/RTS auto-reset wiring may enter download mode automatically.

Do not connect 5 V UART logic to ESP32-S3 pins. Check the module or carrier-board schematic before applying power, and avoid powering one board simultaneously from two outputs unless its power design explicitly permits it.

UART compatibility

The universal firmware.bin is compatible with an ESP32-S3 N16R8 programmed through UART0; the file is not tied to native USB. After OmniRadio starts, however, its interactive firmware console is currently routed to the ESP32-S3 native USB Serial/JTAG interface, not UART0. UART flashing therefore works, but UART alone does not provide the documented /config runtime console.

Espressif describes native USB and UART0 as ESP32-S3 download paths in its firmware-flashing guidance.

Choose a flashing tool

Section titled “Choose a flashing tool”

All tools must write the single firmware.bin at address 0x0. For a first installation or full recovery, the selected tool must also be able to erase the complete flash.

esptool — recommended

Section titled “esptool — recommended”

esptool is Espressif’s cross-platform command-line programmer. It supports native USB and USB-to-UART serial ports, provides explicit erase/write operations, and is the reference method used in the commands below.

ESP Launchpad — browser interface

Section titled “ESP Launchpad — browser interface”

ESP Launchpad is Espressif’s Web Serial programmer. In its DIY/custom-image interface, select the local firmware.bin and address 0x0. It requires a browser with Web Serial support. Use it only when its selected workflow provides the complete erase required for a first installation; otherwise use it for a normal update or choose esptool.

Flash Download Tool — Windows GUI

Section titled “Flash Download Tool — Windows GUI”

Espressif’s Flash Download Tool provides a Windows graphical interface. Select ESP32-S3, regular UART download, firmware.bin, and address 0x0. Use the tool’s complete erase operation before a first installation or recovery, but not before a normal update.

IDE-integrated programmers

Section titled “IDE-integrated programmers”

ESP-IDF, PlatformIO, Arduino IDE, and other environments may use esptool underneath. They are suitable only if they allow the prebuilt combined firmware.bin to be written unchanged at 0x0 and allow the required erase policy to be selected. Do not treat this release as an Arduino sketch, rebuild it for another board profile, or let an IDE substitute its own partition table.

esptool requirements

Section titled “esptool requirements”
  • an ESP32-S3 N16R8 device;
  • a data-capable USB cable or correctly wired 3.3 V USB-to-UART adapter;
  • Python 3 and esptool;
  • an extracted OmniRadio USB release package;
  • the serial port assigned to the device.

Install esptool with:

On Windows the port normally looks like COM5. On macOS it commonly appears under /dev/cu.*; on Linux it commonly appears as /dev/ttyACM0 or /dev/ttyUSB0. Port names vary by board and USB connection.

Enter download mode

Section titled “Enter download mode”

Many ESP32-S3 boards enter the ROM download mode automatically when the programmer opens the port. If connection repeatedly fails, hold BOOT (GPIO0 low), press and release RESET/EN, then release BOOT. The ROM may report DOWNLOAD(USB/UART0). Board labels and automatic-reset circuits differ, so follow the board manufacturer’s instructions where they conflict with this sequence.

Verify the package

Section titled “Verify the package”

Compare firmware.bin with SHA256SUMS.txt before flashing. The included manifest.json must identify ESP32-S3 N16R8, a 16 MB flash size, and offset 0x0.

Section titled “First installation with esptool”

Other compatible ESP32-S3 programmers can be used instead. Select firmware.bin, address 0x0, and 16 MB flash. Erase the device explicitly before the first installation.

After writing, reset or reconnect the device and follow First boot. If the serial connection cannot be opened, close serial monitors and other programs that may own the port, verify the USB cable and driver, and retry download mode.
